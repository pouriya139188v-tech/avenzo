# پروژه AVENZO

این شاخه، نسخه بازسازی‌شده اولیه پروژه AVENZO با Expo و React Native است.

## امکانات فعلی
- ساخت حساب و ورود با ایمیل و رمز عبور از طریق Supabase
- نمایش فید پست‌های متنی
- انتشار پست متنی
- مشاهده و ویرایش نام کاربری و بیوگرافی
- سیاست‌های پایه امنیت دیتابیس (RLS)

## راه‌اندازی
1. وابستگی‌ها را نصب کنید: `npm install`
2. از فایل `.env.example` یک فایل با نام `.env` بسازید.
3. آدرس پروژه Supabase و کلید Publishable/anon را در `.env` قرار دهید.
4. فایل `supabase/schema.sql` را در SQL Editor پروژه Supabase اجرا کنید.
5. برنامه را اجرا کنید: `npx expo start`

## ساخت APK آزمایشی
پس از نصب EAS CLI و ورود به حساب Expo:
`npx eas-cli build --platform android --profile preview`

قبل از اجرای build، پروژه باید به حساب Expo متصل شود. شناسه پروژه EAS را با دستور `eas init` بسازید و تنظیمات را مطابق خروجی آن تکمیل کنید.

## مواردی که هنوز آماده نیستند
ورود پیامکی و ارائه‌دهنده SMS، آپلود عکس و ویدئو، لایک و کامنت، دنبال‌کردن، چت بلادرنگ، اعلان‌های Push، گزارش/مسدودسازی کاربران، کنترل محتوا و آزمون امنیتی کامل هنوز باید پیاده‌سازی و آزمایش شوند. این شاخه به‌تنهایی نسخه نهایی انتشار عمومی نیست.

## امنیت
هرگز کلید Service Role یا رمز عبور Supabase را در برنامه موبایل یا GitHub قرار ندهید. فقط کلید Publishable/anon برای کلاینت مناسب است و دسترسی‌ها باید با RLS محدود شوند.
